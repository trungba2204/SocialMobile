# Orbit M1 — Mobile App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Orbit mobile client — an Expo React Native (TypeScript) app with an original design system, tab + stack navigation, JWT session management, and all Milestone-1 feature screens wired to the existing Spring Boot API, verified by `npx tsc --noEmit`, `npm test`, and a manual run against the running backend.

**Architecture:** Feature-first folders under `src/`. A single Axios instance with request/response interceptors owns auth headers and silent refresh. Session state (tokens, current user) lives in a Zustand store; the refresh token is persisted in `expo-secure-store`, the access token stays in memory only. UI theme (light/dark/system) and transient toasts live in a second Zustand store. Server data is fetched through thin typed `api/*` modules and consumed via small reusable hooks (`usePagedQuery`, `useResource`) that hold local component state — no server-cache library, per the approved stack. React Navigation drives a `RootNavigator` that swaps between an auth stack and the main app based on session status.

**Tech Stack:** React Native (via **Expo SDK 54**, `expo` ~54), TypeScript 5, `@react-navigation/native` + native-stack + bottom-tabs, `zustand`, `axios`, `expo-secure-store`, `expo-image`, `expo-image-picker`, `expo-font` + `@expo-google-fonts/plus-jakarta-sans` + `@expo-google-fonts/inter`, `react-native-reanimated`, `react-native-gesture-handler`, `react-native-safe-area-context`, `@react-native-async-storage/async-storage`, `lucide-react-native` + `react-native-svg`. Testing: `jest-expo`, `@testing-library/react-native`, `@testing-library/jest-native`.

**Spec:** `docs/superpowers/specs/2026-08-31-orbit-social-network-design.md`

**Backend:** `backend/` — already complete. **Do not modify** except the single pre-approved contingency in Task 11 (multipart create-post), and only if that task's verification step proves it necessary.

## Global Constraints

- Mobile framework: **React Native + TypeScript + Expo**. Navigation: **React Navigation**. State: **Zustand**. HTTP: **Axios**.
- **No web app. No Next.js. No plain ReactJS. No Flutter.** Targets **Android and iOS** only.
- The UI is designed by the implementer per the Design section below and spec §7 — never ask the user to choose colors, typography, layout, spacing, icons, or animation.
- Original visual identity. Not a clone of Facebook/Instagram/Messenger branding, layout, or assets. Not a generic "AI default" look.
- Backend API contracts are the source of truth — verified from `backend/src/main/java/com/socialapp/**` in the API Contract Reference below. Do not assume endpoints from the backend plan; use this document's table.
- Access token: in memory only (Zustand), **never persisted**. Refresh token: `expo-secure-store` only. Never log tokens or passwords.
- Every list/detail screen implements explicit **loading (skeleton)**, **empty (illustration + copy + optional action)**, and **error (message + retry)** states. Network failure always offers retry.
- Client-side form validation mirrors backend rules exactly (see API Contract Reference): username `^[a-z0-9_]{3,20}$`; password ≥8 chars with ≥1 letter and ≥1 digit; email format; displayName ≤60; bio ≤280; post content ≤5000; comment ≤2000.
- All colors, fonts, spacing, radii come from theme tokens — **no hard-coded hex, px font sizes, or magic spacing numbers** in feature code.
- Media URLs from the API may be **absolute** (`https://…`, seed data) or **relative** (`/api/media/…`). The `resolveMediaUrl` helper prefixes relative URLs with the API origin; every image goes through it.
- Screens with no M1 backend (Stories, Conversations, Chat) are built as **polished UI backed by local mock data**, isolated behind a `mock/` module and a `// M2`/`// M3` marker, so real endpoints drop in without UI rework.

## API Contract Reference (verified from backend source)

Base URL: `${EXPO_PUBLIC_API_URL}` (default `http://localhost:8080`), API root `/api`.
All routes except `POST /api/auth/{register,login,refresh}` and `GET /api/media/**` require header `Authorization: Bearer <accessToken>`.

**Envelopes**
- Page: `{ content: T[], page, size, totalElements, totalPages, last }` (query `?page=0&size=20`)
- Error: `{ timestamp, status, error, message, path, fieldErrors: [{ field, message }] }`

**DTO shapes**
```
UserDto          { id: number; username: string; displayName: string; avatarUrl: string | null; bio: string | null }
UserProfileDto   UserDto & { coverUrl: string | null; friendCount: number; postCount: number;
                             friendStatus: 'NONE'|'PENDING_OUT'|'PENDING_IN'|'FRIENDS'|'SELF' }
PostMediaDto     { url: string; type: 'IMAGE'|'VIDEO'; position: number }
PostDto          { id: number; author: UserDto; content: string | null; privacy: 'PUBLIC'|'FRIENDS'|'PRIVATE';
                   feeling: string | null; location: string | null; media: PostMediaDto[];
                   createdAt: string; likeCount: number; commentCount: number; shareCount: number; likedByMe: boolean }
CommentDto       { id: number; postId: number; author: UserDto; content: string; parentId: number | null; createdAt: string }
FriendRequestDto { id: number; requester: UserDto; status: string; createdAt: string }
NotificationDto  { id: number; type: 'POST_LIKE'|'POST_COMMENT'|'POST_SHARE'|'FRIEND_REQUEST'|'FRIEND_ACCEPTED'|'MESSAGE'|'STORY_REACTION';

### 3. Authentication flow
1. App launch → `status: 'loading'`, `SplashScreen` visible. `useAuthStore.bootstrap()` reads refresh token from secure store.
   - none → `status: 'signedOut'`.
   - present → `POST /api/auth/refresh` → on success store new `TokenPair`, then `GET /api/auth/me` → set `user`, `status: 'signedIn'`. On failure → wipe secure store, `status: 'signedOut'`.
2. Login/Register → `AuthResponse` → `setSession({ accessToken, refreshToken, user })` (persists refresh token), `status: 'signedIn'`.
3. Axios request interceptor injects `Authorization` from in-memory access token.
4. Axios response interceptor: on `401` (and not an auth endpoint, not already retried) → call a single shared `refreshPromise` → on success update tokens + replay request once → on failure `useAuthStore.signOut()` (→ RootNavigator shows Auth).
5. Logout → `POST /api/auth/logout { refreshToken }` (best-effort) → `signOut()` clears memory + secure store.
6. `ForgotPasswordScreen`: form collects email, client-validates, shows a "If an account exists, you'll get a reset link" confirmation. **No network call in M1** (no endpoint). Marked `// M1: UI only`.

### 4. Design system — identity
**Orbit.** Concept: the people you care about orbit around you. Wordmark set in Plus Jakarta Sans SemiBold, lowercase, with a hairline ring + offset dot glyph (inline SVG in `components/Logo.tsx`). Voice: warm, plainspoken, unhurried. Motifs: concentric rings, soft orbital arcs used sparingly for empty states and the splash.

Distinctive choices (deliberately not a FB clone):
- Feed cards are **edge-to-edge with a 3px leading "privacy hairline"** (accent = PUBLIC, primary = FRIENDS, textSecondary = PRIVATE) instead of a text privacy row.
- Bottom tab bar: 5 slots, center **Create** is a raised pill (primary→accent vertical gradient) not a plain icon.
- Like interaction: `PressableScale` + Reanimated spring (scale 1 → 1.25 → 1) with color fill sweep.
- Stories rail: **rounded-rectangle cards** (not circles), unseen ring is a primary→accent gradient stroke.
- Generous vertical rhythm, few borders, one soft shadow token, large tap targets (min 44×44).

### 9. Zustand state structure
```

  status: 'loading' | 'signedOut' | 'signedIn';
  user: UserDto | null;
  accessToken: string | null;              // memory only
  bootstrap(): Promise<void>;
  setSession(a: AuthResponse): Promise<void>;
  applyTokens(t: TokenPair): Promise<void>;

  themePreference: 'light' | 'dark' | 'system';

Feature/server data is **not** in Zustand — it lives in screen-local state via `usePagedQuery` / `useResource`. Cross-screen freshness handled with `useFocusEffect` refetch + optimistic local updates (like/comment counts, friend status).

### 10. API/service integration strategy
- `api/client.ts`: `axios.create({ baseURL: API_URL + '/api', timeout: 15000 })` + interceptors (Auth §3).
- Each `api/*.ts` exports typed functions returning parsed data (throws `ApiError` on failure). Example:
  `posts.feed(page): Promise<Page<PostDto>>`, `posts.like(id): Promise<LikeResponse>`.
- `api/errors.ts`: `ApiError { status: number; message: string; fieldErrors: Record<string,string> }`; `toApiError(err)` normalizes axios errors (network → `status: 0, message: 'No connection'`).
- `hooks/usePagedQuery<T>(fetcher)`: returns `{ items, loading, refreshing, error, endReached, refresh(), loadMore() }`. Dedupes in-flight, resets on `refresh`.
- `hooks/useResource<T>(fetcher, deps)`: `{ data, loading, error, reload() }`.
- `lib/resolveMediaUrl(url)`: `url.startsWith('http') ? url : API_URL + url`.

### 11. Token / session management
- `api/tokenStore.ts`: `getRefreshToken()`, `setRefreshToken(t)`, `clearRefreshToken()` over `expo-secure-store` (key `orbit.refresh`); `accessToken` held in a module variable + mirrored into `useAuthStore` (interceptor reads the module var to avoid React coupling).
- Single-flight refresh: `let refreshPromise: Promise<TokenPair> | null`. All 401s await the same promise.
- On refresh success: update module var + secure store + `useAuthStore.applyTokens`.
- On refresh failure or missing refresh token during a 401: `useAuthStore.signOut()`.

### 12. Image / media upload strategy
- `expo-image-picker` → `launchImageLibraryAsync({ mediaTypes: 'images', quality: 0.8, allowsMultipleSelection: true, selectionLimit: 4 })`.
- `api/media.ts` builds `FormData`. Avatar/cover: `form.append('file', { uri, name, type })`.
- Create post: `form.append('media', { uri, name, type })` per image, plus the post JSON — see Task 11 for the exact part encoding and the pre-approved backend contingency if RN cannot send a typed JSON part.
- Display: `expo-image` with `contentFit="cover"`, `transition={150}`, `placeholder` blurhash-less gray; every `source` is `resolveMediaUrl(...)`. Post media uses a fixed aspect box (1:1 for single, grid for 2–4) to prevent layout jump.
- Video: `PostMediaDto.type === 'VIDEO'` renders a static poster + play glyph overlay (no playback in M1).

### 13. Loading / error / empty states
- Lists: first load → `Skeleton` rows (3–6); subsequent pages → `ListFooter loading`; empty → `EmptyState`; error → `ErrorState onRetry`.
- Detail screens: skeleton hero → content; error → full-screen `ErrorState`.
- Mutations (like, comment, friend action, publish): optimistic where safe (like), disabled button + spinner where not (publish, friend request); failures → `showToast({ tone: 'error' })` + rollback.
- Global: offline detected by `status: 0` errors → toast "You're offline".

### 14. Dark mode strategy
- `useUiStore.themePreference` (`'system'` default), persisted in AsyncStorage (key `orbit.theme`).
- `ThemeProvider` resolves effective scheme from preference + `useColorScheme()`; provides `{ colors, space, radius, typography, scheme }` via context; `useTheme()` consumer.
- All components read tokens from `useTheme()`. `StatusBar` style follows scheme. Navigation `DefaultTheme`/`DarkTheme` overridden with Orbit tokens.
- Settings → Appearance offers System / Light / Dark segmented control.

// src/lib/format.ts
export function relativeTime(iso: string, now: Date = new Date()): string {
  const then = new Date(iso).getTime();
  const diff = Math.max(0, now.getTime() - then);
  const s = Math.floor(diff / 1000);
  if (s < 45) return 'just now';
  const m = Math.floor(s / 60);
  if (m < 60) return `${m}m`;
  const h = Math.floor(m / 60);
  if (h < 24) return `${h}h`;
  const d = Math.floor(h / 24);
  if (d < 7) return `${d}d`;
  const w = Math.floor(d / 7);
  if (w < 5) return `${w}w`;
  return new Date(iso).toLocaleDateString();
}

export function compactCount(n: number): string {
  if (n < 1000) return String(n);
  if (n < 1_000_000) return `${(n / 1000).toFixed(n % 1000 >= 100 ? 1 : 0)}k`;
  return `${(n / 1_000_000).toFixed(1)}m`;
}

}));

api.interceptors.response.use(
  (r) => r,
  async (error) => {
    const original = error.config;
    const status = error.response?.status;
    const isAuthPath = original?.url?.includes('/auth/');
    if (status === 401 && !original?._retry && !isAuthPath) {
      original._retry = true;
      try {

        refreshPromise = null;
        original.headers.Authorization = `Bearer ${pair.accessToken}`;
        return api(original);
      } catch (e) {
        refreshPromise = null;
        unauthorizedHandler?.();              // registered signOut
        return Promise.reject(toApiError(e));
      }
    }
    return Promise.reject(toApiError(error));
  },
