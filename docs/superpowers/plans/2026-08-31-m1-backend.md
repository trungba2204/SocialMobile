# Orbit M1 — Backend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Milestone 1 Spring Boot REST backend for Orbit — JWT auth plus user, post, comment, like, share, friend, notification, and search APIs, with local media storage and dev seed data, verified by `mvn clean test` and a booting app against local MySQL.

**Architecture:** Feature-first packages under `com.socialapp`, each sliced into `controller/service/repository/entity/dto`. Layering is strict `Controller → Service → Repository`; DTOs (MapStruct) at the controller boundary, JPA entities never serialized. Stateless Spring Security with a JWT filter; global `@RestControllerAdvice` error envelope. Hibernate `ddl-auto=update` for dev with a checked-in `schema.sql` reference.

**Tech Stack:** Java 21, Spring Boot 3.3.x, Spring Web, Spring Security, Spring Data JPA, Hibernate, MySQL 8, JWT (jjwt 0.12.x), MapStruct 1.6.x, Bean Validation, springdoc-openapi 2.6.x, Maven, JUnit 5, Testcontainers (MySQL) + H2 for slice tests, Rest Assured / MockMvc.

**Spec:** `docs/superpowers/specs/2026-08-31-orbit-social-network-design.md`

## Global Constraints

- Backend language: **Java 21** exactly. Build tool: **Maven**.
- Framework set: Spring Boot, Spring Web, Spring Security, Spring Data JPA, Hibernate, **MySQL**, JWT auth, REST, Bean Validation, Swagger/OpenAPI (springdoc).
- DB local dev defaults, in `application.yml` / env vars only — **never hard-coded through source**: host `localhost`, port `3306`, user `root`, password `1234567890`, database `social_network`.
- Every table: primary key, appropriate foreign keys, indexes, unique constraints, `created_at`, `updated_at`.
- DTOs at the controller boundary — **never serialize JPA entities**. Relationships `LAZY`. No unnecessary bidirectional mappings. `spring.jpa.open-in-view=false`.
- Passwords: BCrypt, never stored plaintext, never returned, never logged. Never log JWTs, refresh tokens, or sensitive personal data.
- No business logic in controllers. No giant files. No duplicated code. SOLID.
- Access JWT TTL 15 min; refresh token opaque UUID, 7-day TTL, rotated on every refresh.
- API error envelope: `{ timestamp, status, error, message, path, fieldErrors[] }`. Pagination envelope: `{ content, page, size, totalElements, totalPages, last }`.
- Username pattern `^[a-z0-9_]{3,20}$`; password min 8 chars, ≥1 letter and ≥1 digit.
